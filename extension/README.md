# 题库网关侧边栏扩展

让网关面板出现在 OCS 的专用浏览器里：工具栏一个蓝色书本图标，点开就是侧边栏，
内嵌网关的「总览 / 导出 / 导入 / 复核 / 票源」五个页面，不用再切到别的浏览器。

## 安装

1. 双击本目录的 `install.cmd` —— 会把扩展装到 OCS 的扩展目录
2. **完全退出 OCS**（包括右下角托盘图标），再重新启动
3. 浏览器打开后，工具栏出现蓝色书本图标 → 点它 → 侧边栏打开

## 前提：网关必须开着

扩展只是界面，**数据来自本地网关**。所以先双击 `tiku\start.cmd` 并保持窗口开着，
侧边栏才会显示题目；否则面板会红点提示「网关离线」。

## 侧边栏怎么用

- **刷新**：网关端口变过（被占用会 +1）后重新探测
- **完整页 ↗**：在新标签打开完整的 `127.0.0.1:8321` 管理页
- **启动时自动开标签**：可选。勾选后，OCS 浏览器每次启动会自动开一个网关标签页
  （Chrome 不允许扩展自动弹出侧边栏，这个是接近「随浏览器一起打开」的替代）

五个标签页的功能和完整网页完全一样，见上层 `README.md`。

## 为什么自动弹侧边栏做不到

Chrome 规定 `sidePanel.open()` 必须在用户手势里调用，扩展自己不能在浏览器启动时
擅自弹出侧边栏（防滥用）。所以最接近的做法是：图标常驻 + 点一下即开 + 可选自动开标签。
这是平台限制，不是实现偷懒。

## 卸载

删除 `%APPDATA%\OCS Desktop\downloads\extensions\tiku-panel` 文件夹，重启 OCS。

## 文件

- `manifest.json` — MV3 清单（`sidePanel` 权限 + 本机回环 host 权限）
- `background.js` — 点图标开侧边栏、探测 8321–8325 端口、可选启动开标签
- `panel.html` / `panel.js` — 侧边栏界面（内嵌网关页面）
- `icon.png` — 图标
- `install.cmd` — 一键安装
